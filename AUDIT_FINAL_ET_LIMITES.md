## Contrôles confirmés
- Structure ZIP : test d'intégrité réussi.
- PDF : 176 pages dans la version publique anonymisée, auteur PDF vide et aucune correspondance trouvée dans le texte extractible pour le nom complet ou l’adresse postale recherchés. Les images intégrées ne sont pas garanties exemptes de données identifiantes.
- Les neuf PDF Studi actualisés ont été identifiés comme sources de travail. Les 48+25 fiches de synthèse sont présentes, mais une couverture ligne par ligne de ces neuf supports n’a pas été démontrée. Les PDF originaux ne sont pas publiés dans la bibliothèque.
- Les guides, listes et fiches sont recherchables par un algorithme déterministe (sans génération ni modèle IA).
- Classement : 20 requêtes de référence évaluées par le moteur JavaScript ; 10 requêtes parcourues dans Chromium avec la page assemblée en mémoire. Ouverture et fermeture d’une fiche testées, sans erreur JavaScript sur ces essais. L’URL publique GitHub n’a pas été testée.
- Sources : mentions Cours original vs. Fiche complémentaire clairement distinctes.

## Vérifications NON réalisées ou incomplètes
- Exécution des 13 scripts PowerShell sur Windows + AD : non réalisée ; ne pas affirmer qu'ils fonctionnent partout.
- Deux scripts Bash : syntaxe contrôlée mais logique de chemins, sauvegarde et restauration non certifiée.
- Un exercice PHP : une anomalie de texte source « 1<?php » est connue ; ne pas exécuter tel quel.
- Dix .pkt : leurs topologies internes ne sont pas validées dans Packet Tracer, seules les références sont indexées.
- 77 liens listés : absence de vérification réseau individuelle en direct pour tous, disponibilité non garantie.
- Performance de recherche réelle sur le poste / réseau d’examen : non testée. Le classement reste imparfait pour certains mots très larges et les conditions réseau restent inconnues.
- Exhaustivité de chaque scénario potentiel de l'examen : non démontrable.
- Autorisation de diffusion publique : à vérifier notamment pour les supports de formation protégés.

## Avertissements importants
- La requête est classée automatiquement, mais aucune machine ou réseau n'est configuré par le site.
- Ne jamais publier de vrais mots de passe, comptes personnels, CSV de production ou captures nominatives.
- Garder les identifiants par défaut dans des fiches explicites seulement quand ils sont officiellement documentés ; changer les mots de passe par défaut après la première connexion.
- WDS/MDT : suivre les avertissements Microsoft sur les versions et scénarios non pris en charge.
- Contrôler le résultat final par essai local et en navigation privée sans authentification.
