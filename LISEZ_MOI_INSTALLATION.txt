- Une recherche globale consulte 262 + 216 pages indexées, soit 478 pages.

- Bloc 2 : PDF de 216 pages strictement inchangé.
- Le chapitre 3 regroupe les démonstrations techniques et de nouvelles étapes explicites pour Active Directory. Les éléments administratifs et les en-têtes non techniques ne sont pas intégrés.

POUR INSTALLER SUR GITHUB
1. Extraire ce ZIP dans un dossier sur le PC.
2. Ouvrir https://github.com/cyberworkinch/cyberworkinch.github.io/upload/main
3. Importer TOUS les fichiers extraits à la racine du dépôt, dont le nouveau pdf-pages-data.js.
4. Valider le commit directement sur la branche main.
5. Ouvrir https://cyberworkinch.github.io puis actualiser avec Ctrl+F5.
6. Rechercher GLPI, VLAN ou DHCP : chaque résultat doit afficher une étiquette PAGE N.
7. Cliquer sur un résultat de chaque bloc : le PDF doit s'ouvrir à la page indiquée.
8. Tester dans une fenêtre privée, sans authentification.

IMPORTANT
- Importer les fichiers contenus dans le ZIP, pas le ZIP lui-même.
- Ne pas supprimer les anciens fichiers tant que le site n'est pas validé.
- L'ouverture à la page (#page=N) dépend du lecteur PDF du navigateur ; Edge/Chrome la prennent habituellement en charge.
- La navigation directe atteint la page, pas un emplacement au pixel près dans un paragraphe : le passage correspondant apparaît dans l'extrait et Ctrl+F permet de l'identifier dans la page.
- Il n'y a ni génération de scripts, ni calculateur intégré, ni connexion obligatoire.
